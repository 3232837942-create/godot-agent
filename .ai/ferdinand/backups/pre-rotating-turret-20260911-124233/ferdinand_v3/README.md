# 斐迪南 V3 · 宽体线稿模型

本版依据提供的参考图重新设计宽体底盘、后置固定战斗室和机械细节，以形体协调和展示效果为目标。它是斐迪南风格的艺术化模型，不是按实车测绘复原的历史模型。本次更新修正履带挡板与炮根连接，并加入开火演示。

## 打开查看

双击 `viewer.html`，使用 Chrome 或 Edge 打开。查看器离线运行；移动文件时，请将 `viewer.html`、`viewer.js`、`vehicle_data.js`、`three.min.js`、`fire_effects.js` 放在同一目录。无需安装游戏引擎。已有页面请刷新后查看。

- 拖动旋转，滚轮缩放；选择等距、后斜、侧面、正面、后面或俯视。
- “行驶”演示车轮转动和逐节履带循环；车辆停留在展示位置。
- “瞄准”“后坐”“舱盖”播放对应动作；“分解”展开主要组件。
- “开火”或空格键播放单次开火：炮口闪焰、制退器侧向喷流、快速后坐、缓慢复进和烟尘消散。开火保留当时的炮口瞄准方向。
- “暂停”和进度条可以定格任意动作，检查履带间隙与炮根运动；开火完成后可重播。
- “复位”恢复机械组件；视角和缩放可通过视图按钮复位。

## Blender 中编辑与播放

源文件由 Blender 5.2.1 LTS 生成并重新打开验证。打开后按数字小键盘 0 进入相机视图，F12 渲染当前线稿画面。其他正交相机以 `VIEW_` 开头。时间轴为 30 fps：

| 帧范围 | 动作 |
| --- | --- |
| 1–61 | 履带循环及车轮转动 |
| 81–170 | 有限横向瞄准和俯仰 |
| 181–208 | 后坐与复进 |
| 221–280 | 两个舱盖开合；第 250 帧全开 |
| 301–385 | 单次开火；第 303–305 帧后坐最大，之后复进、消烟 |

查看器中的分解展示由组件位移实现，没有烘焙到 Blender 动画或 GLB 中。

Blender 的 `PRESENTATION_FIRE_FX` 集合提供独立的闪焰和烟雾动画。GLB 包含新增后坐时间段和炮口挂点，不包含这些展示特效；查看器通过 `fire_effects.js` 生成闪焰、冲击波、烟雾与地面扬尘。后续引擎特效应绑定 `SOCKET_MUZZLE`。

线稿效果在 Blender 中使用 Freestyle 和材质，在查看器中使用轮廓线与排线着色。GLB 保留常规材质；导入游戏引擎后需要另外设置线稿着色，不能直接继承 Blender 的 Freestyle 效果。

## 后续用于游戏

已分离车体、战斗室、车轮、左右履带、火炮转向/俯仰/后坐和舱盖，并保留炮口等挂点。当前模型实际网格外包尺寸约 9.05 × 3.77 × 2.97 米，含炮管及外部配件；这些是本模型尺寸。左右每侧 106 节履带，履带板设计宽度 0.64 米。

这是细节展示资产：所有履带实例计入后约 18.55 万三角面，284 个载具层级节点、42 个 GLB 网格，不含 Blender 展示特效。查看器已将重复履带合批绘制，但引擎导入端仍需自行设置实例化、LOD、碰撞体和车辆控制。

GLB 当前包含 233 个按对象导出的动画片段。查看器将这些通道合并到共同时间轴；用于引擎时，应合并并按上表截取动作，或通过组件控制器驱动。Blender 中 +X 为前向、+Z 向上，GLB 转为 Y 向上，导入后需按项目惯例调整车辆前向。

## 验证范围

已重新打开源模型，确认层级、212 节履带、炮口随 0.23 米后坐移动及舱盖最大 80° 开度；GLB 文件结构有效。本次在应用内浏览器运行查看器，检查新开火效果、暂停/进度、复位和瞄准方向保留。

前后挡板改为抬高的分段折弯结构。炮根改为固定装甲座、球面活动炮盾和带内孔的炮管套筒，球面与固定座设计径向间隙 20 mm。新检查覆盖 121 个履带采样时刻（半帧间隔）以及 75 组横向瞄准、俯仰和后坐组合，未检出挡板/履带或炮根/固定装甲相交；原有火炮/甲板、舱盖/顶板及履带/车体和轮组检查也通过。

检查范围限于所列姿态、部件与当前动画，不包括碰撞物理。尚未完成 Godot 内的导入运行验证、碰撞体和驾驶系统。修正前的完整包及生成脚本保存在项目 `.ai/ferdinand/backups/20260911-clearance-fire`。
