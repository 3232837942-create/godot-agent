# FD-184R · 旋转炮塔改造版 V4

参考新图片的斜面炮塔、顶部机枪和侧面附件，对原有宽体底盘进行独立改造。保留蓝灰色线稿、排线及图纸背景。它是架空车型，不再是历史上固定战斗室的斐迪南。

## 打开与控制

双击 `viewer.html`，用 Chrome 或 Edge 打开即可离线查看。请让同目录的 `viewer.js`、`vehicle_data.js`、`three.min.js`、`fire_effects.js` 与 HTML 保持在一起。

- 拖动和滚轮控制观察角度、缩放；六个视图按钮切换正交视角。
- “转塔”演示整塔旋转一周。顶部机枪、两根天线、舱盖、侧面附件和后部篮架随炮塔转动。
- “方位”滑块手动控制 −180°～180°，“俯仰”控制 −4°～14°。
- “开火”或空格键播放闪焰、后坐复进、烟雾和扬尘，保留当前炮塔方位与俯仰。
- 履带循环、舱盖、瞄准及分解展示均保留；“暂停”和进度条可定格检查，“复位”恢复默认姿态。

## 模型与图纸

`ferdinand_technical.blend` 为 Blender 5.2 可编辑源文件。`ferdinand_vehicle.glb` 包含载具分件、旋转层级、挂点、普通材质和动画数据。`ferdinand_drawing.png` 为等距图纸，`ferdinand_four_views.png` 为四视图，`view_*.png` 为各视角、舱盖、开火与炮塔转向图片。

Blender 时间轴为 30 fps：1–61 帧履带循环，81–170 帧炮塔瞄准，181–208 帧后坐，221–280 帧舱盖，301–385 帧开火，401–521 帧整塔旋转一周。

整塔旋转节点为 `TURRET_YAW_PIVOT`，机枪安装座为 `MG_MOUNT`。主炮与机枪均有独立炮口挂点。顶板具有实际舱口，活动炮盾保留内孔和转动间隙。机枪是分件展示模型，尚未加入独立射击动作。

Blender 的闪焰与烟雾单列在 `PRESENTATION_FIRE_FX` 集合；查看器使用独立实时特效。GLB 不包含展示特效或 Blender 的 Freestyle 线条，游戏引擎需要另设对应着色与粒子。GLB 当前按对象导出 233 个动画片段，导入引擎时需合并到共同时间轴或通过控制器驱动。未完成 LOD、驾驶系统、碰撞体或 Godot 内运行验证。

## 已核对的结果

源模型重新打开后确认 302 个载具节点、212 节履带、顶部附件的旋转父节点、实际舱口、360° 旋转和 0.23 米后坐。载具含全部履带实例约 18.29 万三角面；GLB 有 56 个网格，额外的 Blender 展示特效不计入载具网格统计。

炮塔每隔 5°，分别在最低与最高俯仰下检查，共 144 组；另检查 21 组舱盖角度、12 组炮根俯仰与后坐组合，未检出所检查部件之间的相交。这是采样几何验证，不代表任意姿态的物理模拟。

已在应用内浏览器实测六种视图、整塔转向 90° 和完整一周、手动 180° 方位与 14° 俯仰、按当前方位开火、230 mm 后坐、结束归零、舱盖全开、分解复位和履带动作。页面错误日志为空，记录见 `viewer_validation.json`。
