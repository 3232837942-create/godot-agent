# StuG 184 Ausf.A

StuG 184 Ausf.A 是一辆延续蓝灰线稿风格的架空突击炮展示模型，内部版本为 FD-184R V5。本版增加每侧七块分段侧裙板，重做宽承座、固定座圈与旋转护圈，收紧侧面的悬空接缝。几何、交互预览和 Blender 源文件均已更新。

## 查看与操作

直接打开 `viewer.html` 即可离线查看；同目录的四个 JavaScript 文件需要保留。

- 等距、后斜、侧面、正面、后面、俯视六种视图；拖动旋转视角，滚轮缩放。
- **模块**：上一版的大部件分解方式，炮塔和火炮抬升、两侧行走机构外移。
- **分解**：575 个实际网格零件构成的分层展开。包括 212 节履带、14 块裙板、轮组轴向零件、格栅片、装甲板、炮塔座圈和外部附件。细小紧固件部分保留在各自子组件内。
- 两种展开模式均支持暂停、重播和进度滑块。分解按层错时展开，拖回 0% 可收拢。切换其他动作恢复装配状态。
- 行驶、360° 转塔、瞄准、后坐、开火特效、舱盖开合均保留。方位和俯仰滑块用于手动瞄准，空格开火。

## 文件

- `ferdinand_technical.blend`：可编辑模型、原有运动动画、独立零件与分解位移属性、独立展示特效。
- `ferdinand_vehicle.glb`：同一份分件模型与动画。分解层级、位移保存在各节点 extras 中。
- `ferdinand_drawing.png` / `ferdinand_four_views.png`：由本版真实模型渲染的主图、四视图。
- `viewer_*.png`：浏览器实际交互画面截图。
- `validation.json` / `asset_validation.json` / `viewer_validation.json`：针对本次变化的检查结果。

Blender 原有时间轴保持 30 fps：1–61 行驶；81–170 瞄准；181–208 后坐；221–280 舱盖；301–385 开火；401–521 炮塔完整旋转。模块/分解的错时播放由预览器实现，没有烘焙成额外 GLB 动画片段。源文件和 GLB 中的 `explode_offset_blender` 是父节点局部坐标下的 Blender 位移，预览器将其转换为 Y 向上坐标后逐层插值。
